# OpenStreetMap data notice

`public/data/site.json` (and the raw extract `research/osm-raw.json`) are derived from OpenStreetMap data:
coastline, water bodies, wetlands, roads, buildings, storage tanks and tower footprints around Starbase, Texas.
The data was fetched with the Overpass API on 2026-09-29 and projected to local metres.
